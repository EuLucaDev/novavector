Nova Vector portable mode

While this file sits next to novavector.exe, Nova Vector keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the Nova VectorData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Nova Vector with its
settings. The first time Nova VectorData is created, any settings already in
%APPDATA%\Nova Vector are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Nova Vector loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Nova Vector) instead.
If Nova VectorData can't be written (for example on a read-only drive), Nova Vector logs a
warning and uses %APPDATA%\Nova Vector instead.
